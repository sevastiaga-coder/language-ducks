# Моя студия

Это твоя студия разработки. У тебя есть команда: дизайнер, разработчик, тестировщик, ревьюер, инженер по публикации и секретарь. Все они делают проект, который придумал ты.

Ты — **босс**. Твоя работа: придумывать, решать и проверять. Программировать не нужно.

## Как начать

1. Открой эту папку в VS Code.
2. Открой чат Claude Code.
3. Напиши, что хочешь сделать. Обычными словами:

> хочу игру, где надо ловить убегающего кота

Дальше тебя поведут за руку.

## Что будет происходить

| Шаг | Что делаем | Что делаешь ты |
|-----|-----------|----------------|
| 1. Идея | Разбираемся, что за проект и что войдёт в первую версию | Рассказываешь и отвечаешь на вопросы |
| 2. Вид | Придумываем, как это выглядит | Смотришь три варианта и выбираешь |
| 3. План | Раскладываем работу на части | Смотришь, соглашаешься |
| 4. Сборка | Команда делает | Проверяешь руками и говоришь, что не так |
| 5. Публикация | Выкладываем в интернет | Получаешь ссылку и скидываешь друзьям |

Между делом ты узнаешь слова, которыми пользуются взрослые в настоящих студиях. Не специально — просто по ходу работы.

## Что писать в чат

Команд учить не надо, пиши как думаешь. Но если так быстрее:

| Пишешь | Что произойдёт |
|--------|----------------|
| `/idea` | Начать новый проект с идеи |
| `/look` | Придумать, как проект выглядит |
| `/plan` | Разложить работу на части |
| `/build` | Собирать проект |
| `/publish` | Выложить в интернет |
| `/status` | «Что дальше?» — если забыл, на чём остановились |
| `/fix` | «Не работает» — починить |
| `/words` | Слова, которые ты уже знаешь |

Работают и обычные фразы: «не работает кнопка», «сделай кота быстрее», «что дальше», «что такое коммит».

## Когда нужен родитель

Иногда проекту нужен взрослый: подключить сервер, завести аккаунт, дать ключ от какого-нибудь сервиса. Тогда студия скажет об этом и оставит записку в `studio/for-parent.md` — покажешь родителю, когда у него будет время.

Ждать не придётся: студия всегда предложит вариант, который работает уже сегодня.

## Что где лежит

```
studio/          ← память студии: идея, стиль, план, дневник, словарик
app/             ← сам проект, код
stacks/          ← инструкции для команды: на чём делаем проекты
CLAUDE.md        ← правила студии
```

В `studio/` можно заглядывать в любой момент: там записано, что мы решили и почему.

## Для родителя

**Что это.** Набор инструкций, который превращает Claude Code в студию разработки под управлением ребёнка: он ставит задачи и принимает работу, агенты пишут код. Цель — продуктовое мышление и словарь профессии, а не синтаксис языка.

**Как заводится новый проект.** Скопируйте эту папку под именем проекта и откройте копию в VS Code. Один проект — одна папка со своей историей, дневником и репозиторием.

**Что нужно один раз.** Аккаунт GitHub и вход из терминала: `gh auth login`. Список — в `studio/for-parent.md`.

**Публикация.** Веб-проекты выкладываются на GitHub Pages (бесплатно, репозиторий публичный). Серверные — не запускаются: если проекту нужен Railway, база или ключи, студия останавливается, предлагает ребёнку работающий вариант без сервера и оставляет вам записку в `studio/for-parent.md`.

**Приватность.** Перед каждой публикацией отдельный агент проверяет проект на личные данные (фамилия, школа, адрес, телефон, почта, фото) и секреты. Найденное блокирует публикацию до исправления. Ребёнку один раз объясняется, что публичный репозиторий виден всему интернету, и предлагается подписываться игровым именем.

**Что настраивается под вас.** Тон общения, глубина объяснений и список поводов позвать родителя — в `CLAUDE.md`. Стеки и ограничения — в `stacks/`.
