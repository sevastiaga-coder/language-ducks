# Стек: Веб (HTML + CSS + JavaScript)

Стек по умолчанию для всех проектов студии.

## Когда выбирать

**Подходит:** сайты, игры, викторины, калькуляторы, таймеры, генераторы, галереи, тесты, кликеры, рисовалки — всё, что живёт в браузере и чем хочется поделиться ссылкой.

**Не подходит:** проекты, которым нужно помнить данные между разными людьми (общая таблица рекордов, аккаунты, чат), тяжёлые вычисления, работа с файлами на компьютере. Это — Python или зов родителя.

**Главное достоинство:** ноль установок. Двойной клик по файлу — проект работает. Ребёнок может открыть его на любом компьютере, показать другу, отправить ссылку.

## Состав

- HTML — структура страницы
- CSS — внешний вид
- JavaScript — поведение, без фреймворков
- Хранение данных — `localStorage` (запоминает только на этом устройстве, этого достаточно для рекордов и настроек)
- Всё. Никаких npm, сборщиков, React, CDN-ссылок и внешних библиотек.

Исключение — Google Fonts: шрифт можно подключить ссылкой, если он реально нужен стилю.

## Структура проекта

```
app/
  index.html      ← страница; открывается двойным кликом
  style.css       ← все стили
  script.js       ← вся логика
  images/         ← картинки, если есть
```

Проект стал больше 300 строк в `script.js` — разложи логику по нескольким файлам и подключи их как модули. До этого не дроби: один понятный файл лучше пяти маленьких.

## Конвенции

- Имена файлов и папок — латиницей, строчными, через дефис.
- Имена переменных и функций — по-английски, осмысленные: `score`, `startGame`, `catPosition`.
- Текст для пользователя — по-русски, прямо в HTML или в объекте с текстами.
- Цвета, шрифты и размеры — CSS-переменными в `:root`, значения берутся из `studio/style.md`. В коде никаких случайных `#ff0000`.
- Всегда `<meta name="viewport" content="width=device-width, initial-scale=1">` — проект должен нормально открываться на телефоне.
- Пути к файлам — только относительные (`images/cat.png`, а не `/Users/...`). Абсолютный путь сломает опубликованную версию.
- Кнопки — тег `<button>`, а не `<div>` с обработчиком: работает с клавиатуры и на телефоне.

## Команды

- Запустить: открыть `app/index.html` в браузере (`open app/index.html`).
- Посмотреть ошибки: консоль браузера (Cmd+Option+J в Chrome).
- Сборки, тестов и установок нет.

## Публикация

GitHub Pages из ветки `main`. Если Pages отдаёт только корень репозитория, а проект лежит в `app/` — публикуй из корня и проверь относительные пути. После пуша ссылка обновляется примерно за минуту.
