# Стек: Python

Для проектов, которые не помещаются в браузер.

## Когда выбирать

**Подходит:** обработка файлов и таблиц, вычисления, генераторы и анализаторы текста, игры в окне (pygame), боты, автоматизация рутины.

**Не подходит:** всё, чем хочется поделиться ссылкой. Python-проект нельзя открыть в браузере — друзьям придётся ставить Python и запускать код у себя.

**Обязательно предупреди босса** об этом на шаге `/idea`, до начала работы. «Ссылку не пришлёшь» — это заметная потеря для 12-летнего автора, и он должен согласиться на неё осознанно.

## Состав

- Python 3.11+
- Только стандартная библиотека
- `pygame` — если проект про игру в окне
- Больше ничего. Никаких виртуальных окружений, менеджеров пакетов и зависимостей, если без них можно обойтись.

Библиотека всё-таки нужна — она ставится одной командой, а её установка записывается в README.

## Структура проекта

```
app/
  main.py         ← точка входа; запускается одной командой
  game.py         ← логика, если main.py разросся
  data/           ← файлы с данными, если нужны
README.md         ← как запустить
```

Пока проект меньше 200 строк — всё в `main.py`. Дробить раньше времени не надо.

## Конвенции

- Имена — по-английски, `snake_case`: `player_score`, `start_game()`.
- Текст для пользователя — по-русски.
- Никакого ввода паролей, ключей и личных данных в коде.
- Пути к файлам — относительно папки проекта, не абсолютные.
- Программа не должна падать со стектрейсом от неправильного ввода: неверное число — «Не понял, введи число» и повтор вопроса. Ребёнок будет показывать это друзьям.
- Комментарии — только там, где логика неочевидна.

## Команды

- Запустить: `python3 app/main.py`
- Проверить синтаксис: запустить и пройти сценарий руками.
- Поставить pygame (если нужен): `python3 -m pip install pygame`

## Публикация

GitHub Pages не работает — сайта не будет. В GitHub уходит код, README объясняет, как запустить у себя: одна команда, максимум две.
