# Дневник студии

Здесь студия помнит, что происходит с проектом. Читается в начале каждой сессии — по этому файлу любая новая сессия понимает, где мы остановились.

## Где мы сейчас

- **Проект:** Language Ducks
- **Шаг:** публикация
- **Выпуск:** полная игра (оба выпуска приняты): «Перевод» (5 слов) → заставка «ЭТАП 2» → «Обманка» (3 слова) → финал с победителем
- **Что сейчас:** игра готова целиком, проверка перед публикацией пройдена, ждёт разовой настройки GitHub родителем (записка в `studio/for-parent.md`); можно уже играть — двойной клик по «Играть.command»
- **Как играть:** на ноутбуке двойной клик по файлу «Играть.command», на телефоне открыть адрес с большого экрана

- 2026-08-24: первую версию урезали до двух этапов («Перевод» и «Обманка») + подключение телефонов, показ ответов и очки; остальное отложено

- 2026-08-24: выбран стиль «Ночной пруд» — тёмный фон, жёлтое слово со свечением сквозь голубую обводку; тёмный экран лучше всех читается с двух метров за столом

- 2026-08-24: в «Обманке» нельзя голосовать за собственный выдуманный перевод: вариант виден, но серый и не нажимается
- 2026-08-24: план готов — 12 частей, два выпуска
