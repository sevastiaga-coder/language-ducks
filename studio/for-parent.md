# Записки родителю

Сюда студия складывает всё, для чего нужен взрослый. Ребёнок работает дальше без ожидания — записка ждёт, пока у родителя появится время.

**Как читать:** каждая записка — что нужно сделать, зачем это проекту и сколько времени займёт. Сделали — отметьте галочкой, запись остаётся для истории.

## Что просит текущий проект

### Проект Language Ducks готов к публикации — нужен GitHub

**Что это:** игра-викторина про языки, которую сын сделал целиком: игра идёт на экране ноутбука, друзья отвечают со своих телефонов по домашнему Wi-Fi. Обе задуманные части готовы и приняты им же на приёмке.

**Зачем публиковать:** чтобы работа хранилась в интернете и не пропала вместе с ноутбуком, и чтобы друг мог скачать игру и запустить у себя. Живой ссылки, которая просто открывается в браузере, здесь не будет — игра запускается на компьютере, это не сайт.

**Что нужно от вас (разово, на все будущие проекты, ~10 минут):**
1. Завести аккаунт GitHub (если его нет).
2. Установить программу `gh`: `brew install gh` (если нет Homebrew — https://brew.sh).
3. Войти: `gh auth login` → GitHub.com → HTTPS → вход через браузер.
4. Проверить: `gh auth status` — должно написать «Logged in to github.com».

**Про приватность — уже сделано, для вашего спокойствия:**
- Репозиторий будет **публичным** — это обсудили с сыном отдельно.
- Проект прошёл отдельную проверку перед публикацией. Фамилии, школы, адреса, телефона, почты и ключей в нём нет.
- Вся история сохранений переподписана игровым именем **Sevastiaga**, которое сын выбрал сам. Настоящие имя и фамилия из истории удалены полностью.
- Найденную при проверке дыру (через игру можно было прочитать любой файл на ноутбуке по домашней сети) закрыли до публикации.

**Что будет, если не делать:** ничего не сломается. Игра полностью работает с ноутбука, запускается двойным кликом по файлу «Играть.command». Откладывается только хранение в интернете.

### Игра через интернет, а не только по домашнему Wi-Fi
**Зачем проекту:** сейчас игроки подключаются к ноутбуку по общему Wi-Fi — играть можно только в одной комнате. Чтобы позвать друга из другого города, игре нужен сервер в интернете (например, Railway).
**Что сделать:** завести Railway, подключить проект, выдать ребёнку адрес.
**Сколько времени:** ~15 минут.
**Что будет, если не делать:** игра полностью работает за столом — это её основной сценарий. Откладывается только игра на расстоянии.
**Срочность:** не сейчас. Это идея из списка «потом», к ней вернёмся после первой версии.

## Про безопасность — коротко

- Репозитории публичные: всё, что попадает в проект, видно в интернете. Перед каждой публикацией проект автоматически проверяется на личные данные (фамилия, школа, адрес, телефон, фото).
- Ключи и пароли никогда не проходят через чат и не попадают в репозиторий.
- Проекты, которые собирают данные других людей (логины, почту, оплату), не делаются без вашего участия.
