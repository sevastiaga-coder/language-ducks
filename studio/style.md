# Как выглядит проект

_Это единственный источник правды по внешнему виду. Разработчик берёт цвета, шрифты и размеры только отсюда._

## Стиль: Ночной пруд

Тёмная комната и неон: свет только от экрана, каждый ответ вспыхивает — как ночная вечеринка.

Главный приём стиля: **жёлтое слово со свечением сквозь голубую обводку**. Любой крупный текст, на который все смотрят (слово задания, название игры, счёт, имя победителя) — жёлтая заливка + тонкая голубая обводка + голубое свечение вокруг. Всё остальное — спокойное и тихое, чтобы главное было видно с двух метров.

## Цвета

| Роль | Код | Где используется |
|------|-----|------------------|
| Фон | `#0B1026` | фон страницы, поле ввода |
| Основной | `#35D8FF` | обводки, рамки, свечение, подписи-подсказки, счёт в таблице |
| Акцент | `#FFE14D` | кнопки, слово задания, правильный ответ, лидер |
| Текст | `#DCE6FF` | обычный текст, имена игроков |
| Второй текст | `rgba(220,230,255,.62)` | подписи, «ответили 3 из 5», номера мест |

**Производные оттенки того же тёмно-синего** (не считаются отдельными цветами):

| Роль | Код | Где используется |
|------|-----|------------------|
| Панель | `#141A3A` | большая карточка экрана, телефонный блок |
| Карточка | `#1B2350` | карточка одного ответа игрока |
| Карточка-верная | `#1B2A55` | карточка правильного ответа (плюс жёлтая рамка) |
| Текст на жёлтом | `#06122B` | буквы внутри жёлтой кнопки |

### Готовые CSS-переменные

```css
:root {
  --bg:            #0B1026;
  --panel:         #141A3A;
  --card:          #1B2350;
  --card-ok:       #1B2A55;
  --main:          #35D8FF;
  --accent:        #FFE14D;
  --text:          #DCE6FF;
  --text-dim:      rgba(220,230,255,.62);
  --on-accent:     #06122B;

  --font-head: Orbitron, "Trebuchet MS", system-ui, sans-serif;
  --font-body: Rubik, system-ui, -apple-system, "Segoe UI", sans-serif;

  --radius:    18px;
  --radius-s:  12px;

  --edge:      1px solid rgba(53,216,255,.55);
  --card-edge: 1px solid rgba(120,150,255,.30);
  --ok-edge:   2px solid #FFE14D;
  --divider:   1px solid rgba(120,150,255,.25);

  --glow-panel:  0 0 40px rgba(53,216,255,.18);
  --glow-btn:    0 0 26px rgba(255,225,77,.55);
  --glow-ok:     0 0 22px rgba(255,225,77,.35);
  --glow-word:   0 0 18px rgba(53,216,255,.85), 0 0 40px rgba(255,225,77,.35);

  --bg-lights:
    radial-gradient(ellipse at 20% 0%,   rgba(53,216,255,.16), transparent 55%),
    radial-gradient(ellipse at 90% 100%, rgba(255,225,77,.10), transparent 50%);
}
```

Фон страницы: `background: var(--bg) var(--bg-lights) no-repeat fixed;`

## Шрифты

Только эти два, оба из Google Fonts. Подключить один раз в `<head>`:

```html
<link href="https://fonts.googleapis.com/css2?family=Orbitron:wght@600;800;900&family=Rubik:wght@400;600;800&display=swap" rel="stylesheet">
```

- **Заголовки и цифры:** Orbitron, 800. Слово задания, название игры, адрес подключения, очки, имена в таблице, текст на кнопках.
- **Текст:** Rubik, 400 обычный / 800 жирный. Всё остальное: подписи, подсказки, списки, ответы игроков.

Шрифты держать в переменных `--font-head` / `--font-body`. Если интернета нет — работают запасные системные, вёрстка не ломается.

## Размеры

### Экран ноутбука (смотрят с 1–2 метров)

- Ширина содержимого: до 1100px, по центру
- Отступ между блоками: 24px, внутри панели 28px
- Скругление панели: 18px, карточек и кнопок: 12px
- Слово задания: `clamp(48px, 7vw, 110px)`
- Заголовок экрана / название игры: 40–56px
- Имя игрока в списке: 26px
- Подпись-подсказка: 18px
- Плашка этапа («ЭТАП 1 · ПЕРЕВОД»): 16px, буквы вразрядку `.08em`, жёлтый фон, тёмные буквы

### Экран телефона (под палец)

- Ширина: вся, поля по 16px
- Отступ между блоками: 16px
- Высота кнопки: **60px**, ширина — во весь экран, текст 22px
- Высота поля ввода: 58px, текст 22px (меньше 16px нельзя — телефон начнёт зумить)
- Кнопка варианта при голосовании: минимум 64px высотой, между кнопками 12px
- Ничего нажимаемого мельче 48×48px

## Правила

**Кнопка (главная).** Жёлтый фон `--accent`, тёмные буквы `--on-accent`, Orbitron 800, голубая рамка 2px, скругление 12px, свечение `--glow-btn`. При нажатии: уходит вниз на 2px и свечение становится ярче. Неактивная (нельзя нажать): фон прозрачный, рамка и текст — `--text-dim`, без свечения.

**Кнопка второстепенная.** Прозрачный фон, голубая рамка 2px, голубые буквы. Для «назад», «пропустить».

**Карточка ответа.** Фон `--card`, рамка `--card-edge`, скругление 12px. Слева мелко имя игрока (`--text-dim`, 14px), крупно сам ответ (Orbitron, 24px, `--text`), справа очки.

**Подсветка правильного.** Фон `--card-ok`, рамка `--ok-edge` (2px жёлтая), свечение `--glow-ok`, сам текст ответа жёлтый. Плюс подпись «ВЕРНО» жёлтым. Только цветом не различаем — всегда есть ещё и подпись.

**Крупное слово (главный приём).**
```css
.word {
  font-family: var(--font-head); font-weight: 900;
  color: var(--accent);
  -webkit-text-stroke: 2px var(--main);
  paint-order: stroke fill;
  text-shadow: var(--glow-word);
}
```

**Панель.** Фон `--panel`, рамка `--edge`, скругление 18px, свечение `--glow-panel`.

**Появление.** Ответы и результаты выезжают по одному, с задержкой 150мс — чтобы за столом успевали смотреть. Никаких других анимаций.

**Обязательно.** Всё работает на телефоне без горизонтальной прокрутки. Цветов пять, шрифтов два — больше не добавлять.

# Экраны

Устройств два. **Ноутбук** — общий экран, его видят все, на нём ничего не нажимают. **Телефон** — личный, на нём всё нажимается.

## Экран ноутбука

### Л1: Сбор игроков

- Сверху: название **LANGUAGE DUCKS** крупным словом (жёлтое со свечением)
- В середине — **главное на экране**: адрес подключения `192.168.x.x:8000` огромными цифрами Orbitron, в жёлтой рамке. Под ним подпись голубым: «Зайди с телефона по этому адресу»
- Ниже: сетка из карточек зашедших игроков (до 10), в каждой имя. Пустые места — пунктирные рамки-заглушки
- Внизу: счётчик «Игроков: 4 из 10»
- Нажатий нет. Новый игрок появляется в сетке сам, с лёгкой вспышкой. Игру запускает первый зашедший игрок со своего телефона

### Л2: Задание «Перевод»

- Сверху: плашка «ЭТАП 1 · ПЕРЕВОД» и номер вопроса «Слово 3 из 5»
- В центре — **главное**: само иностранное слово гигантскими буквами (жёлтое, голубая обводка, свечение)
- Под словом: язык слова — «немецкий», голубым
- Ниже: полоса имён всех игроков. Кто уже ответил — имя горит жёлтым с галочкой; кто думает — приглушённое `--text-dim`
- Внизу: «Ответили 3 из 5»
- Нажатий нет. Когда ответили все — экран сам переключается на Л3

### Л3: Показ ответов «Перевода»

- Сверху: то же слово, но уже поменьше (36px), рядом голубым правильный перевод
- В центре — **главное**: карточки ответов всех игроков, выезжают по одной. Правильные подсвечены жёлтой рамкой + подпись «ВЕРНО»
- На каждой карточке справа — начисленные очки: «+100» жёлтым или «+0» приглушённым
- Внизу: короткая таблица очков, лидер выделен голубой подсветкой строки
- Нажатий нет. Через несколько секунд — следующее слово (Л2) или следующий этап

### Л4: «Обманка», часть 1 — придумываем

- Сверху: плашка «ЭТАП 2 · ОБМАНКА» и подпись «Придумай перевод, чтобы все поверили»
- В центре — **главное**: редкое слово гигантскими буквами (жёлтое со свечением), под ним язык — «исландский»
- Ниже: список имён — кто уже прислал свою выдумку (жёлтый + галочка), кто ещё пишет
- Внизу: «Придумали 3 из 5»
- Нажатий нет. Когда прислали все — экран сам переходит на Л5

### Л5: «Обманка», часть 2 — голосование

- Сверху: то же слово поменьше, подпись «Где настоящий перевод?»
- В центре — **главное**: список всех вариантов вперемешку (выдумки игроков + настоящий), каждый в карточке с крупным номером в голубом кружке. **Авторов не видно**
- Порядок вариантов перемешивается один раз и одинаков на всех телефонах
- Ниже: кто уже проголосовал
- Нажатий нет. Голосуют с телефонов. Когда проголосовали все — Л6

### Л6: Итог «Обманки»

- Сверху: слово и подпись «Настоящий перевод:»
- В центре — **главное**: настоящий вариант, жёлтая рамка + свечение + подпись «НАСТОЯЩИЙ». Остальные варианты гаснут, и у каждого открывается автор: «это придумал Пётр»
- Под каждым вариантом — имена тех, кто за него проголосовал
- Ниже: очки строчками — «Даня нашёл настоящий +100», «Пётр обманул двоих +200»
- Внизу: таблица очков
- Нажатий нет. Дальше — следующее слово этапа или финал

### Л7: Финал

- Сверху: слово **ПОБЕДИТЕЛЬ** голубым, вразрядку
- В центре — **главное**: имя победителя гигантскими буквами (жёлтое со свечением) и его очки
- Ниже: таблица всех игроков по местам — номер, имя, очки. Первые три места крупнее остальных
- Внизу: подпись «Обновите страницу, чтобы сыграть ещё раз»
- Нажатий нет

## Экран телефона

### Т1: Вход

- Сверху: **LANGUAGE DUCKS** жёлтым со свечением, поменьше чем на ноутбуке
- В центре — **главное**: одно поле ввода «Как тебя зовут?» (до 12 символов) и кнопка **ИГРАТЬ** во весь экран
- Нажал ИГРАТЬ → имя появляется на ноутбуке в сетке игроков, телефон уходит на Т2
- Если имя пустое или уже занято — под полем голубая подсказка, экран не переключается

### Т2: Ожидание

- Сверху: «Ты играешь как **Даня**»
- В центре — **главное**: крупная надпись «Смотри на большой экран» и под ней, что сейчас происходит: «Ждём остальных» / «Скоро задание»
- Первому зашедшему игроку (и только ему) внизу — кнопка **НАЧАТЬ ИГРУ**
- Нажал НАЧАТЬ ИГРУ → на ноутбуке появляется первое задание, все телефоны переходят на Т3
- Экран сам меняется, когда игра идёт дальше. Нажимать больше нечего

### Т3: Ввод ответа

- Сверху: «Ты играешь как **Даня**», рядом номер задания
- Под ним: задание одной строкой — «Переведи: **der Schmetterling**» или «Придумай перевод: **hundslappadrífa**»
- В центре — **главное**: поле ввода (58px, крупный текст, автофокус) и кнопка **ОТВЕТИТЬ** во весь экран
- Внизу: «Ответили 3 из 5»
- Нажал ОТВЕТИТЬ → уходит на Т5 («Ответ принят»)
- Пустой ответ отправить нельзя — кнопка неактивная, пока поле пустое

### Т4: Голосование

- Сверху: «Где настоящий перевод?» и само слово
- В центре — **главное**: список вариантов, каждый — кнопка во всю ширину, минимум 64px, с номером в голубом кружке. Порядок такой же, как на ноутбуке
- Свой собственный вариант в списке есть, но он приглушён и не нажимается — за себя голосовать нельзя
- Нажал вариант → он загорается жёлтой рамкой, остальные гаснут, телефон уходит на Т5
- Переголосовать нельзя

### Т5: Ответ принят / результат раунда

- Сверху: «Ты играешь как **Даня**»
- Пока ждём остальных — **главное**: большая жёлтая галочка и «Ответ принят», ниже свой ответ и «Ответили 3 из 5»
- Когда на ноутбуке показали результат, этот же экран меняется: **главное** становится начисление — «+100» гигантскими жёлтыми цифрами со свечением (или «+0» приглушённым), под ним строчка «Ты угадал» / «Мимо» / «Пётр клюнул на твою выдумку»
- Ниже: «Твои очки: 340», «Ты на 1 месте»
- Нажимать нечего. Экран сам уходит на Т3 или Т4, когда начнётся следующее задание
