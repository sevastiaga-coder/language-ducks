# Шаг 5: Показать миру

Ради этого момента всё и делалось. У босса должна появиться ссылка, которую он скинет другу и тот откроет её на своём телефоне. Не смазывай этот момент техническими подробностями.

Вход: принятый выпуск.

## Шаги

### 1. Разговор про интернет — до, а не после

Первая публикация в проекте — скажи один раз, спокойно, без запугивания:

> «Сейчас проект станет виден всему интернету — по ссылке его сможет открыть кто угодно. Поэтому одно правило: в проекте не должно быть твоей фамилии, школы, адреса и телефона. Имя — можно, если хочешь, но многие берут игровое.»

Спроси, каким именем подписать проект. Это его решение, и оно про личные границы — не решай за него.

### 2. Ревью

Запусти **reviewer**: приватность, секреты, качество.

Вердикт «нельзя» — не публикуй. Переведи причину на человеческий и спроси разрешения исправить: «В тексте на главной осталась твоя фамилия — её увидит любой, кто откроет ссылку. Заменю на игровое имя?».

### 3. README

Запусти **scribe**: README проекта — что это, как играть, ссылка. Это витрина: первое, что видит человек, открывший репозиторий.

### 4. Публикация

Запусти **publisher** (режим 2): репозиторий на GitHub, код туда, GitHub Pages, живая ссылка.

Нет авторизации в `gh` — это разовая настройка родителем. Допиши в `studio/for-parent.md`, скажи боссу: «Нужна разовая настройка от родителя, минут на пять. Записку я оставил — покажи ему».

### 5. Вручи ссылку

Отдельным коротким сообщением, без технических деталей вокруг:

> **Готово. Твой проект в интернете:** https://…
>
> Открывается на любом телефоне и компьютере. Можно скидывать друзьям.

Термины: **коммит** — «сохранённая версия проекта. Как точка сохранения в игре: всегда можно вернуться»; **публикация (деплой)** — «выложить проект в интернет, чтобы он открывался по ссылке».

Для Python-проекта ссылки на сайт не будет — скажи прямо, без извинений: «Код лежит в интернете, друзья могут скачать и запустить у себя. Ссылкой, которая просто открывается, делятся только веб-проекты — будет такой, сделаем».

### 6. Запиши и подведи итог

Запусти **scribe**: дневник (проект опубликован, ссылка), словарик, ссылка в раздел «Проект» в CLAUDE.md.

Скажи, что проект теперь можно обновлять: «Доделаем что-нибудь — ссылка обновится сама, ничего заново делать не надо».

Спроси, что дальше: следующий выпуск, идеи из «потом» в `studio/idea.md`, или новый проект.

## Правила

- **Без ревью не публикуем никогда.**
- Ссылка — отдельным сообщением. Не прячь её в середине абзаца с техническими деталями.
- Ссылка не открылась сразу — так и скажи: «Публикация занимает минуту, подождём». Не молчи и не показывай ошибки.
- Обновление опубликованного проекта — тот же **publisher** (режим 3), боссу достаточно фразы «Обновил, посмотри».
